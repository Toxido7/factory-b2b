# Security review (Sprint 5)

| Threat                      | Protection                                                                                                             | Where                                | Status                                                                              |
| --------------------------- | ---------------------------------------------------------------------------------------------------------------------- | ------------------------------------ | ----------------------------------------------------------------------------------- |
| Guessed password            | bcrypt, 8 to 72 chars with letter + number, same error for unknown email and wrong password, dummy hash against timing | `auth.service.js`, `password.js`     | done                                                                                |
| Brute force                 | Rate limits per IP, plus 20 failed logins per hour per account                                                         | `rateLimiters.js`                    | done. Counters are in memory, so they reset on restart and work for one server only |
| Stolen access token         | 15 minutes, HS256 pinned on verify                                                                                     | `tokens.js`                          | done. A token stays valid up to 15 min after disable or role change                 |
| Stolen refresh token        | httpOnly cookie, stored as SHA-256 hash, rotation, replay revokes all sessions                                         | `auth.service.js`, `auth.cookies.js` | done                                                                                |
| Database leak               | Passwords are bcrypt hashes. Refresh, verify and reset tokens are SHA-256 hashes                                       | `schema.prisma`                      | done                                                                                |
| Wrong role                  | `authenticate` + `authorize` on every admin mount, contract tests                                                      | `app.js`                             | done                                                                                |
| Reading other people's data | Owner in the query, 404 not 403                                                                                        | `requests.repository.js`             | done                                                                                |
| Fake prices                 | Server recalculates everything from the database                                                                       | `requests.service.js`, `pricing.js`  | done                                                                                |
| Mass assignment             | Zod strips unknown fields. Role never comes from the client                                                            | `*.schema.js`                        | done                                                                                |
| SQL injection               | Prisma only, no raw SQL                                                                                                | repositories                         | done                                                                                |
| HTML injection in emails    | `escapeHtml`                                                                                                           | `escapeHtml.js`                      | done                                                                                |
| Bad uploads                 | Magic bytes, 5 MB, random file names, strict filename regex                                                            | `imageType.js`, `uploadImage.js`     | done                                                                                |
| Email discovery             | Same answer for forgot-password and login errors                                                                       | `auth.service.js`                    | done. Register answers 409 for an existing email (accepted, the user needs to know) |
| Headers and CORS            | helmet, CORS only for `CLIENT_URL`                                                                                     | `app.js`                             | done                                                                                |
| Secrets                     | Validated env, `.env` never committed, JWT secret at least 32 chars                                                    | `env.js`, `.gitignore`               | done                                                                                |
| Secrets in logs             | pino redacts Authorization and Cookie                                                                                  | `logger.js`                          | done                                                                                |
| CSRF                        | Refresh cookie is SameSite=Lax, path `/api/auth`, CORS locked                                                          | `auth.cookies.js`                    | low risk, accepted                                                                  |
| Docs exposure               | Swagger is off when `NODE_ENV=production`                                                                              | `app.js`                             | done                                                                                |
| HTTPS, `trust proxy`        | Cookie `Secure` in production                                                                                          | DevOps spike                         | open                                                                                |
| Backups                     | Offsite database backups with a tested restore                                                                         | Sprint 6                             | open                                                                                |
